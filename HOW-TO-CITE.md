# How to Cite This Work

Thank you for your interest in **Behavioral CCC: A Behavioral Structure Paradigm for Intelligent Systems**.

If you use ideas, figures, or concepts from this repository in academic or technical work, please cite it using the following reference.

---

## Recommended Citation

Tan, Sizhe.  
**Behavioral CCC: A Behavioral Structure Paradigm for Intelligent Systems.**  
GitHub Repository.

(If available, include the Zenodo DOI associated with the release.)

Example:

Tan, S. (2026).  
*Behavioral CCC: A Behavioral Structure Paradigm for Intelligent Systems.*  
GitHub.  
https://github.com/sizhet/Behavioral-CCC

## Citation with DOI (Preferred)

Tan, S. (2026).

https://doi.org/10.xxxx/zenodo.xxxxxx
